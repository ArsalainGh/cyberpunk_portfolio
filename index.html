05 // About Me

Who I Am

Hey! I'm Arsalain Gharsallaoui, a final-year Computer Science student at ISIGK (Institut Supérieur d'Informatique et de Gestion de Kairouan), Tunisia. I'm passionate about building things for the web — from landing pages to full-stack applications — and I care deeply about open-source software.

My journey into tech started with curiosity about how websites work, which quickly spiraled into web development, and then into a fascination with Linux and cybersecurity. I believe secure, accessible software should be the norm, not the exception.

I built projects like TunDev and SecureDevHub because I noticed a gap: Tunisian and Arab IT students lack free, localized, quality resources. I want to help close that gap — one project at a time.

When I'm not coding, you'll find me reading about ethical hacking, tinkering with Linux distros, or exploring the latest in web technologies.
